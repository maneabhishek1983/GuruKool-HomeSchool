# QR Scanner Integration Guide

## Overview

The GuruKool Teacher mobile app includes a fully functional QR code scanner for teacher check-in/check-out using student-specific QR codes generated by the web application.

## Architecture

### Components

1. **QR Scanner Screen** (`lib/screens/qr_scanner_screen.dart`)
   - Uses `mobile_scanner` package for camera-based QR scanning
   - Supports torch/flash toggle
   - Camera switching (front/back)
   - Real-time barcode detection
   - Location tracking via `geolocator` package

2. **Check-In Success Screen** (`lib/screens/check_in_success_screen.dart`)
   - Displays successful check-in confirmation
   - Shows session details (student ID, time, location)
   - Navigation options to home, session history, or scan another QR

3. **Router Configuration** (`lib/config/router.dart`)
   - Route: `/qr-scanner` - QR scanner screen
   - Route: `/check-in-success` - Success confirmation with session data passed via `extra`
   - Route: `/session-history` - View all sessions

## QR Code Format

### Web App Generation

The web app generates QR codes using [src/services/teacher-qr.service.ts](../../src/services/teacher-qr.service.ts):

```json
{
  "type": "teacher_auth",
  "teacherId": "uuid-string",
  "studentId": "uuid-string",
  "parentId": "uuid-string",
  "timestamp": 1234567890,
  "signature": "hmac-sha256-signature"
}
```

### Mobile App Parsing

The Flutter app parses this format in `_parseQRCode()` method:

```dart
final Map<String, dynamic> qrData = jsonDecode(code);

// Validates:
// 1. QR code type == "teacher_auth"
// 2. Required fields present (teacherId, studentId, parentId, signature)
// 3. Timestamp not expired (24 hours)

return {
  'student_id': qrData['studentId'],
  'parent_id': qrData['parentId'],
  'teacher_id': qrData['teacherId'],
  'signature': qrData['signature'],
  'qr_code_id': code,
};
```

## Session Flow

### 1. Teacher Scans QR Code

```
User → QR Scanner Screen → Detects barcode → Parses JSON
```

### 2. Validation

```
Parse QR → Validate type → Check expiration → Extract IDs
```

### 3. Location Capture

```
Request permission → Get GPS coordinates → Format as "lat,long"
```

### 4. Create Session in Supabase

```dart
await Supabase.instance.client
  .from('teacher_sessions')
  .insert({
    'teacher_id': user.id,
    'student_id': qrData['student_id'],
    'parent_id': qrData['parent_id'],
    'session_start': DateTime.now().toIso8601String(),
    'location': '${position.latitude},${position.longitude}',
    'qr_code_used': code,
  });
```

### 5. Success Navigation

```
Insert session → Navigate to /check-in-success → Display confirmation
```

## Database Schema

### Table: `teacher_sessions`

Defined in [supabase/migrations/004_teacher_sessions.sql](../../supabase/migrations/004_teacher_sessions.sql)

```sql
CREATE TABLE teacher_sessions (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  teacher_id UUID NOT NULL REFERENCES auth.users(id),
  student_id UUID NOT NULL,
  parent_id UUID NOT NULL,
  session_start TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  session_end TIMESTAMP WITH TIME ZONE,
  duration_minutes INTEGER,
  location JSONB,
  qr_code_used TEXT,
  verification_status TEXT DEFAULT 'pending',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## Troubleshooting

### Issue: Camera Permission Denied

**Solution**: Check Android settings → Apps → GuruKool Teacher → Permissions → Enable Camera

### Issue: Location Permission Denied

**Solution**: Session will still be created but without GPS coordinates

### Issue: QR Code Expired

**Error**: "QR code expired (X hours old)"
**Solution**: Re-generate QR code from web app (24-hour expiration)

### Issue: Invalid QR Code Type

**Error**: "Invalid QR code type: login"
**Cause**: Scanning wrong QR code (login QR instead of teacher_auth QR)
**Solution**: Use QR codes from teacher assignment flow, not login screen

### Issue: Session Not Created

**Possible Causes**:

- No internet connection
- Supabase credentials missing (check `.env`)
- User not authenticated
- Database RLS policies blocking insert

**Debug Steps**:

1. Check Flutter logs: `flutter logs`
2. Verify Supabase connection: `SUPABASE_URL`, `SUPABASE_ANON_KEY`
3. Test with demo credentials
4. Check Supabase RLS policies

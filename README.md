# GuruKool HomeSchool

A mobile application for tracking teacher visits for homeschooling. This app allows parents to track teacher timesheets and enables teachers to check in and check out of sessions.

## Features

- User authentication for parents and teachers
- Dashboard for teachers to view upcoming and completed sessions
- Session management with detailed information
- Offline support with automatic syncing
- Location tracking for teacher visits

## Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- Next.js

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/maneabhishek1983/GuruKool-HomeSchool.git
```

2. Install dependencies
```bash
cd GuruKool-HomeSchool
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Building for Production

```bash
npm run build
npm run start
```

## TypeScript

This project uses TypeScript for type safety. Run type checking with:

```bash
npm run type-check
```

## Deployment

The application can be deployed to various platforms including Vercel, Netlify, or any other hosting service that supports Next.js applications.

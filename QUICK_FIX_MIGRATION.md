## What This Migration Creates

### Tables

1. **`parent_qr_codes`** - QR codes generated by parents
   - Contains QR code data and image
   - Links to parent and student
   - Has expiration and active status

2. **`timesheet_entries`** - Teacher check-in/check-out records
   - Records check-in and check-out timestamps
   - Auto-calculates duration in minutes
   - Stores location and session notes
   - Enforces constraints (check-out after check-in)

### Automatic Features

- **Duration Auto-Calculation**: Trigger calculates duration when teacher checks out
- **Updated_at Auto-Update**: Trigger updates timestamp on any change
- **Row Level Security**: Enforces parent/teacher data isolation

### Views

- **`teacher_timesheet_summary`** - Aggregated hours per teacher
- **`parent_timesheet_summary`** - Aggregated hours per parent/student

## Common Errors & Solutions

### Error: "relation already exists"

**Solution**: Migration already applied. No action needed.

### Error: "foreign key violation"

**Solution**: Ensure these migrations are applied first:

1. `001_initial_schema.sql`
2. `002_data_sheets_and_extended_features.sql`

### Error: "function already exists"

**Solution**: Drop existing function first:

```sql
DROP FUNCTION IF EXISTS update_updated_at_column() CASCADE;
DROP FUNCTION IF EXISTS calculate_timesheet_duration() CASCADE;
```

Then re-run the migration.
